# Squeeze

A tall, messy stack of records slides onto the bed of a hand press. The platen comes down, the wheel spins, the
stack is squared up and squeezed to a quarter of its height; the excess puffs out as dust and paper scraps that
stay where they fall. The block gets an edge, a file label and two straps. Beside it the size counts down
(48 → 3 MB) and the old value lands struck above. ~1.3 s on a forward arrival, then it rests.

**Suits** compression, consolidation, summarisation, dedupe, "one file instead of forty", cost or size cuts: any
claim that is a before → after shrink. **Not for** growth claims (use a rising number), or when the shrink is not
a real measured number.

## Re-skin it

- **Copy**: rewrite the `h2`; set `.count` `data-from` (before) and `data-to` (after), the struck `.st-squeeze-was`
  text and `.st-squeeze-unit`. Keep one number pair; never invent one.
- **The stack**: 14 `.st-squeeze-sheet` groups, each `--i` (0 = bottom), `--jx` / `--r` (its mess). Recolour the
  `.st-squeeze-face` fills to the product's records (photos, logs, tokens, layers); the tabs can be its brand
  colours. The label on the pressed block can carry the product's mark (keep it under 80 × 48).
- **Colours** come from the section: `--field`, `--brand` (wheel, straps, sheet tints), `--brand-2` (sheet tints,
  tabs). Text uses `--ink-auto`; the pegboard is a tint of it. The block's label shows `__MARK__`.

## Timing (one 1.5 s timeline)

0–0.3 s stack slides in and rights itself, platen starts down · 0.45 s contact · 0.45–0.7 s squeeze, dust,
scraps, count down · 0.7–1.0 s platen lifts, block springs, edge, label, straps · 1.0 s struck old value ·
1.3 s rest. Resting CSS = final pose (print, reduced motion, ←).
