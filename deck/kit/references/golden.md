# Golden decks

Ranked. Contact sheets of every slide are next to this file (`golden/*.jpg`); read them before designing.
Local sources exist on the user's machine; read the HTML when you need an implementation detail.

**They set the bar for the rules and the craft, never the look.** Each one looks like its own product: tftf is a
dusk sky because its story is an evening, Prompt Fu is the game, Common Grounds is the video. In the hr-2026
backtest four lanes copied tftf's look (tile reveal, headline top-left over white cards, painted gradient fields)
and the user rejected all four as "slight remasking of the research agent slides". Copy how they think, not how
they look.

## Why the zero-revision decks worked

Prompt Fu and Common Grounds had a look that already existed (the game, the video) and real assets. Click took
12 rounds because its brief mixed two references, invented a half-empty live-mirror layout and used the app's
neutral UI. tftf took about 8 rounds on colour, chrome and clicks before the rules above existed. The skill's
job is to start where those decks ended.
