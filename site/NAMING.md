# Name the directory Revisionpedia

Use **Revisionpedia** with the descriptor **Singapore economic revisions**. An editor looking up an old figure can tell what the directory indexes. Keep **Recall Press** on “Cover my briefing”, where it names the service that delivers a replacement slide. The plain product name is stronger for the service. For a searchable directory, Revisionpedia with the geographic descriptor is clearer.

| Candidate | Obvious use found in web search, 19 November 2026 | Decision |
| --- | --- | --- |
| Revisionpedia | Exact searches for “Revisionpedia” and “Revisionpedia” with “directory” returned no results. | Recommend. “Revision” can also mean exam preparation, so keep the descriptor beside the masthead. |
| Restatpedia | Exact searches for “Restatpedia” and “Restatpedia” with “directory” returned no results. | Short, but “restat” asks the visitor to work out the pun before they know what they can look up. |
| Figurepedia | An existing encyclopedia of anime figure manufacturers uses the exact name. [Existing directory](https://figurepedia.com/about) | Drop. Both sites would be reference directories. |

This was an obvious-use search. Domain availability, registered names and trademark status remain unverified.
