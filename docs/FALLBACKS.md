# If a morning test fails

Use the same numbers as the test card. Write down which route actually ran. Save unfinished or failed platform results alongside any local demonstration.

1. **Skill discovery.** Open Desktop → Extensions → Skills → Install Skill. Supply the entire recall-press folder from skills. If the picker asks for an archive, use workspace/recall-press.zip. Run skills/recall-press/sync.sh in the checkout to rebuild it. Start a new task. If discovery still fails, attach the entire folder as task files and ask the agent to follow SKILL.md. A successful folder run establishes the scripts work in that environment. It leaves Skill discovery open.
2. **Slide or map delivery.** In a task with the checkout open, paste “Run ./demo.sh and give me the first map and corrected members’ briefing it prints.” Open those files from Finder. On slide four check the 5.0% sentence and dated source; the original still says “stalled.” Services on slide three stays at 0.6%. The separate electronics sentence has no verified series. The full demo also corrects the sales deck and updates the newsletter’s comparison. If pip is unavailable, use the existing checkout environment on this Mac.
3. **Independent reading.** The chair’s deck has four verifiable sentences across two series. Score each by sentence: no manufacturing growth → now wrong (0.0% to 5.0%); below 1% → now wrong; GDP expanded 2.9% → number only (revised to 4.2%); October’s estimate of 2.9% → still true. The unchanged extractor finds three. Record the agent’s first count and verdicts before giving it any hints. If it misses one, ask it to read slide two again and register all four with --claims. Mark the retry as assisted.
4. **Scheduling.** For Desktop, keep the client running and the Mac awake. Open Scheduled Tasks → Execution History and record the actual trigger and location. Check that both tasks used the same Morning folder and project archive. For cloud execution, copy the complete Skill, originals, archive and register to a persistent folder and register the originals there so their paths resolve. If the clock never fires, use Run now twice or run the Skill manually with the schedule trigger and --record. Mark those runs manual. A failed source check has no quiet verdict. A new official revision on the second check is a valid change; repeat once on unchanged data to test quiet handling.
5. **Email access.** Allow the macOS Mail connector to read the selected notice or select one in the Microsoft 365 Outlook connector. Otherwise paste the release text, date and public link and ask for the same check. Record the input as pasted. A forwarded notice triggers an official check; a historical replay uses the date of the original release. Gmail access is undocumented.
6. **Hashmeta.** Check that the custom connector is enabled in a new desktop task, with access to the intended site. If listing succeeds but draft writing fails, capture each result separately. Save the proposed title and page copy as a local draft for the site owner. Publish nothing to Hashmeta during this test.
7. **QwenWork Page.** Try the web Page publisher in the same workspace with the sample HTML attached. Verify the page in a new tab. If publishing or scripts/downloads fail, show the standalone local map and its adjacent corrected files. A published screenshot can show the map visually; label it static.
8. **Narrated export.** If the generator returns short clips, ask it to join them with a single voiceover. If export still fails, use iMovie on the Mac: import the three screenshots, set durations to 6, 7 and 7 seconds, record the narration, then export File → Video and Audio at 1080p with High quality for MP4. Play the final file and record that assembly was local.
