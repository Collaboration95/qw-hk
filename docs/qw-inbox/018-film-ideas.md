# 018 · Film and slide ideas for the Recall Press submission

You are the creative lead for Recall Press's hackathon submission film and slides. Work only inside this project
folder. Write everything into `docs/qw-outbox/018-film-ideas/`. Do not commit, push, delete or publish anything.

## 1. Look at the source material (list and open these folders yourself)
- `site/v2/src/` — the live product site (https://revisionpedia.geo.hashmeta.tech): `home-01-hero.html` (the Recall
  desk window), `home-02-run.html` (the agent run log), `home-03-history.html`, `home-04-grid.html`, `system.css`
  (colours, type, motion). Screenshots: `site/v2/out/v3/*.png`.
- `context/taste/README.md` — the owner's three reference decks and what they like.
- `deck/v1/` — the first pitch deck (old story and look), `deck/kit/references/taste.md` — the slide rules.
- `README.md` section "One revision, two answers", and `docs/submission/description.md`.
- `qwenwork-out/08-media/` — the media you made earlier (opening, transitions, narration).

## 2. Come up with the films
The product line is: **"Your sources change. Your deck updates itself."** When a source a deck cites is revised,
Recall Press rewrites the sentence it broke and hands back the updated PowerPoint; the editor approves.
Propose **three** submission films (each about 10 shots, hard cuts between shots, slide-style motion graphics inside
each shot, light look from `system.css`, ≤ 2:45). For each: title, one-line idea, and a shot table (shot, picture,
on-screen caption, narration, seconds). Use only real numbers from the files (e.g. 0.0% → 5.0% → 4.6%, 60 figures,
57 revised, 18 sentence-breaking). Be honest: the editor approves every change; sample decks are founder-written.
Write it to `docs/qw-outbox/018-film-ideas/STORYBOARD.md`. Say which film you would pick and why.

## 3. Make one shot
Build the opening shot of your favourite film as a single self-contained HTML file
`docs/qw-outbox/018-film-ideas/shot-01.html` (1920×1080, uses the colours and Inter from `system.css`, one CSS
animation of about 6 seconds that loops). Reuse markup from `site/v2/src/home-01-hero.html` if useful.

## 4. Slide titles
Write `docs/qw-outbox/018-film-ideas/SLIDES.md`: ten slide headlines for the pitch deck (full sentences, 4–10 words,
ending with a period, no topic titles), each with the one visual that proves it.

## 5. Report
Write `docs/qw-outbox/018-film-ideas/REPORT.md` (what you read, what you made, which film you pick), then create the
empty file `docs/qw-outbox/018-film-ideas/DONE`.
